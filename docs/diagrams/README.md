# Pocket Mocap Diagram Set

The diagrams describe the two-subsystem system organization:
- `poandroid`: Android phone capture subsystem.
- `popc`: PC operator, calibration, reconstruction, and review subsystem.

Supported operation modes:
- single phone mode;
- multi-phone mode.

The PC subsystem includes ChArUco intrinsic calibration and ChArUco extrinsic calibration. Both subsystems participate in the seven-model ML evidence stack.
